# Обзор проекта: Локальный Windows-Агент "Jarvis"

## Цель
Создать локального AI-агента на Python, который управляет Windows 10, браузером Chrome и файловой системой. Агент должен быть управляемым, предсказуемым и не зацикливаться.

## Архитектура (3 слоя)
1.  **Мозг:** Локальная модель в Ollama (например, Qwen 8B/14B). Только она принимает решения.
2.  **Руки:** MCP-серверы. `windows-mcp` для окон/кликов/файлов. `playwright-mcp` для управления Chrome.
3.  **Оркестратор:** Python-скрипт (ты его напишешь), который связывает Ollama и MCP, следит за лимитом шагов (максимум 10) и останавливает работу, если модель тупит.

## Главные правила
- **Никакой самодеятельности:** Агент выполняет ТОЛЬКО команду пользователя. Если не получилось за 10 шагов — стоп, отчет об ошибке.
- **Никаких отказов:** Модель должна быть настроена на выполнение задачи. Если она говорит "не могу", оркестратор переспрашивает или использует другой инструмент.
- **Все логи в файл:** Каждый шаг (запрос, ответ, вызов инструмента) пишется в `agent.log`.
