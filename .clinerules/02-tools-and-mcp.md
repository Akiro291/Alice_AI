# Инструменты и MCP

## MCP Серверы (в mcp.json для Ollama/Cline)
1.  **windows-mcp:** Запускается через `uvx windows-mcp serve`. Дает доступ к окнам, кликам, вводу текста, запуску .bat и PowerShell.
2.  **playwright-mcp:** Запускается через `npx @playwright/mcp@latest`. Дает доступ к Chrome (навигация, клики, парсинг).

## Библиотеки Python (в requirements.txt)
- `ollama` (для связи с моделью)
- `mcp` (для управления MCP-серверами из кода)
- `playwright` (если нужен прямой доступ к браузеру без MCP)
- `python-dotenv` (для конфигов)

## Скрипт Оркестратор (что ты должен написать)
Напиши `main.py`, который:
1.  Читает задачу из консоли.
2.  Отправляет её в Ollama с описанием инструментов.
3.  Если Ollama просит вызвать инструмент — вызывает его через MCP-клиент.
4.  Возвращает результат в Ollama.
5.  Если Ollama просит "terminate" или превышен лимит шагов (10) — останавливается.
